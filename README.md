# HA রঙিন পাঠশালা

বাচ্চাদের জন্য মজার শেখার ওয়েব অ্যাপ (PWA) — বাংলা বর্ণমালা, ইংরেজি বর্ণমালা, ফল-ফুলের নাম ও সংখ্যা, সাথে সাউন্ড, কুইজ ও স্কোর সিস্টেম।

**Built by HA Tech BD**

---

## ফোল্ডার স্ট্রাকচার

```
ha-ronginpathshala/
├── index.html
├── manifest.json
├── service-worker.js
├── css/
│   └── style.css
├── js/
│   ├── data.js      ← সব কনটেন্ট (বর্ণ, শব্দ, ইমোজি) এখানে
│   └── app.js        ← অ্যাপের লজিক
└── icons/            ← সব সাইজের আইকন
```

## লোকালি টেস্ট করা (Chromebook Linux)

Chromebook-এর Linux (Crostini) টার্মিনালে:

```bash
cd ha-ronginpathshala
python3 -m http.server 8080
```

তারপর ব্রাউজারে যান: `http://localhost:8080`

## GitHub-এ পুশ করা

```bash
cd ha-ronginpathshala
git init
git add .
git commit -m "HA রঙিন পাঠশালা - প্রথম ভার্সন"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

## GitHub Pages দিয়ে লাইভ করা

1. GitHub রিপোজিটরির **Settings → Pages**-এ যান
2. "Branch" এ `main` সিলেক্ট করুন, ফোল্ডার `/ (root)` রেখে **Save** দিন
3. কিছুক্ষণ পর লিংক পাবেন: `https://<your-username>.github.io/<repo-name>/`

## নতুন কনটেন্ট/বর্ণ যোগ করতে চাইলে

`js/data.js` ফাইলে প্রতিটি বিভাগের (vowels, consonants, english, fruits, flowers, numbers) `items` অ্যারেতে নতুন অবজেক্ট যোগ করলেই হবে — কোনো HTML/CSS বদলাতে হবে না।

## নতুন আপডেট (v2)

- ফল ও ফুল মিলিয়ে ১১৪টি আইটেম যোগ হয়েছে
- আরবি হরফ (২৮টি) নতুন বিভাগ হিসেবে যোগ হয়েছে, প্রতিটির বাংলা নাম ও ইংরেজি উচ্চারণ (Alif, Ba, Ta...) সহ
- সংখ্যা এখন ১ থেকে ১০০ পর্যন্ত, প্রতিটির বাংলা বানান (একুশ, বাইশ...) ও ইংরেজি বানান (Twenty-One...) সহ
- কুইজ এখন লেভেলে ভাগ করা (প্রতি লেভেলে ১৫টি আইটেম), প্রতি লেভেলে আলাদা স্টার সেভ থাকে
- সাউন্ড সিস্টেম উন্নত করা হয়েছে — এখন ডিভাইসে থাকা সবচেয়ে ভালো মানের ভয়েস (Google ভয়েস অগ্রাধিকার) অটো বেছে নেয়, ভাষাভেদে (বাংলা/ইংরেজি/আরবি) আলাদা speed/pitch সেট করা

### সাউন্ড নিয়ে একটা সত্যি কথা
এটা ব্রাউজারের বিল্ট-ইন Text-to-Speech (Web Speech API) ব্যবহার করে — ইন্টারনেট/অ্যাকাউন্ট ছাড়াই ফ্রি কাজ করে, কিন্তু ভয়েসের মান ডিভাইসের উপর নির্ভর করে। Android + Chrome-এ সাধারণত ভালো "Google বাংলা/Arabic" ভয়েস পাওয়া যায়। সত্যিকারের রেকর্ড করা মানুষের কণ্ঠের মতো "নিখুঁত" সাউন্ড চাইলে পরবর্তীতে একটা ক্লাউড TTS API (যেমন Google Cloud TTS) যোগ করা যায় — তবে সেটার জন্য ইন্টারনেট কানেকশন ও একটা API key লাগবে (কিছুটা খরচও হতে পারে)।

## নোট

- এটা একটা PWA — ব্রাউজারে "Add to Home Screen" করে মোবাইলে অ্যাপের মতো ইনস্টল করা যাবে।
- অফলাইনেও চলবে (service worker দিয়ে ক্যাশ করা)।
- কোনো ব্যাকএন্ড/Firebase লাগে না — স্কোর ডিভাইসেই (localStorage) সেভ থাকে।
- হোম পেইজে থাকা অবস্থায় দুইবার ব্যাক করলে অ্যাপ বন্ধ হওয়ার চেষ্টা করবে (ইনস্টল করা PWA-তে এটা সবচেয়ে ভালো কাজ করে)।
